About Trinket

Trinket was an open source browser-based coding platform that let you write and run code without installing anything.

Originally created by Elliott Hauser and Brian Marks, Trinket was built to make coding accessible to learners everywhere. This instance was maintained by STEM Learning to support its courses; new public accounts are no longer created here.

Features

  • Wrote and ran Python, HTML, and more in the browser
  • Created and shared interactive coding projects
  • Built courses with embedded code examples
  • Required no downloads or installation

Open Source

Trinket was released under the CC0 1.0 license. You can still run your own instance, contribute to development, or use the code however you like.
